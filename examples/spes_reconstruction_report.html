SPES reconstruction and matched agent comparison

Completed result

This comparison does not demonstrate a consistent multi-agent advantage over the single agent. Multi-agent AUROC: 0.6988; single-agent AUROC: 0.6960. The paired change is +0.0027, with a 95% patient-bootstrap interval [-0.0091, +0.0148].

All 75 numerical training/evaluation runs and 175 matched agent cases are complete. The 175 evaluations represent 35 patients across five repeated splits.

AUROC measures whether clinician-labelled SOZ electrodes rank above non-SOZ electrodes; 0.5 is chance ranking. Clinical treatment benefit requires seizure or outcome measurements. This retrospective classification comparison uses a disclosed different cohort from the paper: 35 patients / 2,145 electrodes / 304 SOZ positives here, versus the published 35 / 2,066 / 298. The difference remains unresolved.

All 75 reconstruction runs complete; cohort/implementation discrepancies prevent a claim of exact paper reproduction. Current stage: All scheduled comparisons complete.

Source and task

Norris et al., MLHC / PMLR 252 (2024) classifies the same eligible electrodes from measured single-pulse electrical stimulation responses. This is retrospective localization, not treatment efficacy or next-stimulation selection. Official source code; public dataset.

35 patients, 2145 electrodes, 304 SOZ-positive electrodes. Published counts match: False.

Five repeats of five patient-level folds, with three training folds, one validation fold and one test fold. Metrics average patients within each fold, then average the 25 folds. Clinical labels remain in the scoring process.

Reproducibility limitations and remaining stages

  • The released notebook does not provide original RNG states, fold manifests or checkpoints. The rerun freezes explicit seeds and lexical file order; exact decimal agreement cannot be guaranteed.
  • The original development PyTorch build is replaced by released 2.1.0+cu121. Windows path separators are normalized. The original RandomNoise transform is loaded without unrelated optional spectral dependencies; numerical model source files remain unchanged.
  • The published Appendix C median/MAD threshold differs from the released code's pooled validation threshold. Both are reported. If the appendix rule is undefined for a validation patient, it is marked as undefined rather than silently repaired.
  • Published selected hyperparameters are used. This does not rerun the original ten-trial Optuna search.
  • Channel sensitivity is a separately recorded stage using saved checkpoints. Its original inference RNG and bootstrap implementation are not published.
  • Independent Engel outcome labels and the exact outcome-model specification have not been verified in the public release. Figure 4B cannot be claimed reproduced without them. Resection or SOZ labels must not be substituted for outcomes.
  • The example table follows a predetermined held-out patient. The original spatial Figure 6 patient was not specified; that exact figure was not reproduced.

Evidence files: cohort.json, training/protocol.json, training/split_*.json, per-run predictions and metrics, table1_reproduction.json, and native ScienceClaw agent artifacts. Missing stages remain pending; published values never stand in for executed results.

The numerical CNN and Transformer models were trained on the training folds. Request counts and configured output caps are matched; measured token totals may differ. Provider SDK response metadata is saved for every successful request. Malformed returned score vectors consume a request; the policy retains its previous scores (initially the shared Transformer). Such states are explicitly labelled, with no extra request or invented agent explanation.

single: 1370 accepted outputs, 29 malformed outputs, 1 counted uncaptured failures; multi: 1363 accepted outputs, 37 malformed outputs, 0 counted uncaptured failures.

A halted episode may continue only its unspent attempts. An uncaptured failure is retained as a labelled carry state, with unknown provider token consumption. Previously completed requests are never replayed; a partial token total is a lower bound. Case elapsed times can include the recovery pause.

Separate API token calibration

The initial 3,824-token combined ceiling truncated 6 of 45 captured responses. The stopped trial contains 47 attempted requests and 2 unresolved in-flight attempts. These records are preserved separately and excluded from performance comparisons; settings were changed based on truncation, without selecting by localization accuracy.

The fresh formal comparison uses an identical 8,192-token combined ceiling and low reasoning effort for both strategies. Captured calibration token usage is a lower bound because in-flight responses were not captured. Formal and calibration request/token consumption are reported separately.

Checks cover source hashes, disjoint patient splits, label order, numerical and agent scoring, request budgets, role schedule, provider usage records and native ScienceClaw artifact hashes/lineage.
