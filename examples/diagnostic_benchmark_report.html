ScienceClaw · sub-003 · gemini mode

Diagnostic stimulation selection

Multi-round specialists, a single agent and a random policy under the same experiment budget.

Observed result

None of the three policies retrieved a generator-reference region in its final top ten. This run does not demonstrate successful localization or a multi-agent advantage; improving and validating the shared inference method is a priority.

This is a one-patient development benchmark against a released stimulation-generator susceptibility hypothesis. The shared localizer is a SEEG-only response-ranking heuristic, not full Bayesian VEP inversion or a clinically validated diagnostic model. No therapeutic efficacy is measured. Single realizations of the Gemini policies cannot establish multi-agent superiority. Random repetitions describe policy variability on this same patient, not independent patient replication.

Matched-budget results

Every strategy receives the same candidate pool, waveform, simulation seed, post-stimulation window, localizer and no-stimulation calibration. Each queried site costs one experiment even when a cached response is reused. The two nonrandom Gemini strategies use one proposal plus one reflection per experiment. Reference accuracy is computed only after policy execution and is never returned to agents.

Higher localization metrics are better. Average precision summarizes precision/recall over ranking thresholds. Recall@10 is the fraction of reference regions in the ten highest-ranked regions. Ties use threshold-grouped AP, average-rank AUROC and expected hits at the top-k boundary. Positive prevalence is the tied-score baseline, not the expected finite-sample AP of random rankings. Random reference repetitions: 20.

Feedback and collaboration

Four roles act in round-robin order. Each records a prediction, observes one SEEG response, updates the common numerical ranking and writes a reflection. Later agents receive prior proposals, predictions, measured summaries and reflections. The single agent receives the same tools and observation content. Reflections express model-generated assessments; they do not count as independently verified scientific conclusions. The shared numerical localizer determines all scored rankings.

Hidden reference and scientific limits

The two-level stimulation parameter subgroup is checked against the released lower-threshold subgroup. It is not a clinical gold standard or the complete spontaneous-seizure EZ hypothesis.
