# One-slide project update

[Editable English PowerPoint](anya_seizure_localization.pptx)

This slide explains the diagnostic goal, recorded-response replay and scoring
in everyday language. Both charts and their embedded data are editable.

The left chart compares random selection (0.740) with the score-focus computer
rule (0.762) on all 35 patients. The right chart reports a separate five-patient
pilot: the same rule scores 0.812, one AI assistant 0.796, and two assistants
0.794. The score is mean within-patient SOZ AUROC, not treatment success.
The difference between the full study and pilot scores is not a longitudinal
improvement, and the pilot does not establish a collaboration advantage.

Sources are the completed [physical-query numerical study](../spes-agent-v11-report.md)
and [independent-proposal pilot](../spes-agent-v16-report.md). Speaker notes
contain exact values, paired uncertainty intervals and methodological limits.
Chart data round those values to the three decimals displayed on the slide.

The newer legacy-cohort experiment is excluded. Its independent audit was
stopped at the user's request. No new API request or experiment is needed to
use this presentation.
